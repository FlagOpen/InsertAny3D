# InsertAny3D 环境安装说明

## 环境结构

项目只维护三套运行环境：

| 环境 | 位置 | 使用模块 | Python / PyTorch |
| --- | --- | --- | --- |
| 主环境 | `third_party/TRELLIS/.venv` | TRELLIS、SAGS、LangSAM、3DGS 渲染 | 3.11 / 2.5.1+cu121 |
| Hunyuan 环境 | `third_party/Hunyuan3D-2/.venv` | Hunyuan3D-2 | 3.12 / 2.7.1+cu118 |
| GIM 环境 | `third_party/gim/.venv` | GIM、RoMa、Depth Anything | 3.9 / 1.12.1+cu113 |

MVInpainter 是对比实验模型，不属于主流程，本教程不为其创建环境。

## 系统要求

- Linux x86_64；
- NVIDIA 驱动支持 CUDA 12.4；
- Conda；
- CUDA Toolkit 12.4，用于编译主环境扩展；
- CUDA Toolkit 11.8，用于编译 Hunyuan 扩展；
- `git` 和可用的 PyPI、PyTorch 下载网络。

服务器有多套 CUDA 时，可以通过环境变量指定位置：

```bash
export CUDA_12_HOME=/opt/data/private/ljn/cuda-12.4
export CUDA_11_HOME=/opt/data/private/ljn/cuda-11.8
export CONDA_BIN=/opt/data/private/ljn/miniconda3/bin/conda
```

RTX 3090 默认使用计算能力 8.6。其他显卡需要在安装前修改：

```bash
export TORCH_CUDA_ARCH_LIST=8.6
```

## 安装

进入项目根目录：

```bash
cd InsertAny3D
```

一次安装全部三套环境：

```bash
bash tools/install_environments.sh all
```

也可以分别安装：

```bash
bash tools/install_environments.sh main
bash tools/install_environments.sh hunyuan
bash tools/install_environments.sh gim
```

安装脚本会固定主要版本，下载并检出固定提交的 CUDA 扩展源码，再进行本地编译。构建源码默认保存在 `.build/environment_sources`，不会放入虚拟环境。

## 模块使用哪个 Python

TRELLIS 和 SAGS 都使用主环境：

```bash
third_party/TRELLIS/.venv/bin/python
```

Hunyuan3D-2 使用：

```bash
third_party/Hunyuan3D-2/.venv/bin/python
```

GIM 使用：

```bash
third_party/gim/.venv/bin/python
```

SAGS 的 .venv 是指向主环境的符号链接；TRELLIS-old 仅保留历史文件，不参与安装。

## 验证

运行统一验证脚本：

```bash
CUDA_VISIBLE_DEVICES=0 bash tools/verify_environments.sh
```

成功时最后一行应为：

```text
INSERTANY3D_THREE_ENVIRONMENTS_READY
```

验证内容包括：

- 三套 PyTorch 均能访问显卡；
- TRELLIS 的 flash-attn、xformers、kaolin 和栅格化扩展；
- SAGS 的 GroundingDINO、SAM、`simple_knn` 和高斯栅格化扩展；
- LangSAM 和 SAM2 使用主 TRELLIS 环境；
- Hunyuan 的两个自定义扩展；
- GIM 的核心依赖。

验证只检查规定环境下的正确执行路径，不检查模型输出效果。

## 权重和数据

虚拟环境不包含模型权重。安装完成后仍需按项目 README 将权重放到对应目录。环境合并不会移动或复制权重，也不会改变 `data` 目录。

## 历史环境记录

`code/environment` 和各第三方仓库中的 `ENVIRONMENT_VERSIONS.txt` 是上传前各个旧环境的冻结记录，只用于追踪历史版本。实际安装以根目录 `environment/requirements-*.txt` 和本教程为准。
